# ♟️ Chess Game (HTML, CSS, JavaScript)

A fully interactive **Chess Game** built using **HTML, CSS, and Vanilla JavaScript**.  
This project demonstrates not only the logic of chess rules but also modern front-end techniques for layout, styling, and DOM manipulation — all without external frameworks.  

---

## 🚀 Features
- 🎨 **Clean UI** – board designed with responsive HTML & CSS grid.  
- ♔ **Standard chess rules** – legal moves, captures, and check detection.  
- 🔄 **Turn-based play** – players alternate between white and black pieces.  
- ✨ **Highlighting** – shows possible moves for selected pieces.  
- 📱 **Responsive** – playable on desktop and mobile browsers.  

---
